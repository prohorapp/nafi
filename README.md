# НАФИ

## О проекте

Проект выполняется в рамках конкурса проектов Skillbox.

В качестве проектного кейса команда разрабатывает цифровое решение для Аналитического центра НАФИ.

Цель проекта — создать продающий лендинг и интерактивный прототип самостоятельного подключения платформы «Цифровой гражданин» (https://it-gramota.ru), позволяющий клиенту пройти полный путь от знакомства с продуктом до оформления подключения без участия менеджера.

### Пользовательский сценарий

Изучение возможностей платформы → выбор параметров подключения в конфигураторе → заполнение формы → оформление договора → имитация оплаты → экран успешного подключения.

Проект предусматривает разработку адаптивной мобильной версии (390×844 px).

### Основная задача

Создать понятный пользовательский путь, который поможет потенциальному клиенту быстро понять ценность продукта, самостоятельно подобрать подходящий вариант подключения и успешно завершить оформление.

# Правила работы

- Одна задача = один Issue.
- Каждая задача должна иметь понятное название и описание.
- Все задачи заводятся и отслеживаются в GitHub Project.
- Перед началом работы задача переводится в статус **In Progress**.
- После завершения разработки задача переводится в **Review**.
- После проверки задача переводится в **Done**.
- Все изменения фиксируются в соответствующих задачах GitHub.
- Оперативные обсуждения ведутся в Telegram, итоговые решения фиксируются в GitHub.
