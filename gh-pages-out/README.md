# НАФИ MVP

Лендинг MVP платформы «Цифровой гражданин» от НАФИ.

## Структура

- `index.html` — основной лендинг
- `404.html` — страница ошибки GitHub Pages
- `assets/css/style.css` — стили
- `assets/js/app.js` — логика калькулятора, формы и экрана успеха
- `assets/img/` — иллюстрации и иконки
- `bootstrap.sh` — простой скрипт для запуска локального сервера

## Запуск

Откройте терминал в папке `nafi-mvp` и выполните:

```bash
./bootstrap.sh
```

Откроется локальный сервер на `http://localhost:8000`.

## Как работает

- Адаптивный лендинг без React и сборщиков
- Sticky header
- Интерактивный конфигуратор с выбором тарифа и расчётом стоимости
- Регистрационная форма с валидацией
- Просмотр договора и выбор способа оплаты
- Экран успешного подключения

## Примечания

Проект создан для GitHub Pages и готов к публикации как статический сайт.
